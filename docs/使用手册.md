# Luma Translate 1.1.0 使用手册

Windows 运行 Setup 安装；macOS 打开 DMG，把 Luma Translate 拖入 Applications。M1 使用同一份 Universal 安装包，无需 Rosetta。系统要求和首次权限见根目录 INSTALL.txt。

## 查询与阅读

在主窗口输入英文单词、短语或谚语，点击“离线查询”。词典保存已收录的完整中文释义；英文解释、音标、词形、例句与学术用法按可用字段显示，长内容可以滚动。缺少的字段会明确提示。查询失败的语块仅显示带说明的逐词参考，不能把它当作整句翻译。

在其他应用的英文上连续快速点击两次鼠标右键，可进行本地屏幕取词。普通右键会等待双击判定时间后回放，因此菜单出现可能有短暂延迟。Windows 需要安装系统英文 OCR 组件；Mac 需要用户授予辅助功能和屏幕录制权限，屏幕录制刚授权后请重新启动应用。

在 AI 设置中配置 DeepSeek 或 Gemini 密钥，并确认允许向所选服务发送英文后，可以点击“AI 用法”，或右键长按约 420 ms 后拖拽框选。单词和不超过 30 个英文词的语块采用详细词典模式；较长内容采用整句翻译。点击的词与其上下文作为不同字段传入。离线查询不会自动请求 AI。

## 学术英语与覆盖范围

词库含 767,778 条基础记录，其中 365,230 条含多个词，158,731 条有英文解释，217,915 条有词库音标；另补充 34 条学术术语、语块和谚语，包含原创双语例句和用法说明。数量来自固定 ECDICT 数据版本，不代表每条都包含全部字段或所有义项。

AI 详解要求按义项编号配对中文释义、英文解释与双语例句，并补充可靠的英美音标、学术领域和常见搭配；未知内容需要明确说明。生成内容会标注来源，不能视为权威词典或保证穷尽所有学科含义。

## 后台运行与朗读

Windows 安装后的开始菜单入口直接打开主界面。直接运行 LumaTranslate.exe 默认进入托盘；带 --show 参数打开主界面。隐藏或关闭窗口后仍可在托盘恢复，完全退出使用“退出”。Mac 可从菜单栏重新打开主窗口。

朗读使用系统本地英语声音。离线词典、屏幕 OCR 和本地朗读不要求 API 密钥。屏幕截图仅在本机内存处理；调用 AI 时发送识别后的英文与相关上下文。

## 图标与外观

保留原有蓝紫色双页、文字声波和点击星芒图标。Windows 主窗口改用独立 512 px PNG，避免放大托盘图标；图案本身不变。macOS 采用原生毛玻璃材质，Windows 采用浅色圆角面板。

## 验证范围

Windows 进行了词典、OCR、AI 结果格式和原生界面检查；macOS 在 Apple M1 虚拟机与 Intel Mac 环境从 DMG 复制并启动同一个 Universal 应用，检查词库、查询、窗口渲染、关闭重开和 Vision OCR。详细记录随交付包提供。全局鼠标手势、系统权限授权后的完整取词流程、实际 AI 服务质量和朗读听感仍需在使用环境确认。
