# Luma Translate v4 · 右键双击即译 EN → 简体中文

> 这是 Luma Translate 的完整使用手册。快速上手和下载请看 [项目主页](../README.md)。

Luma Translate 是一款面向汉语使用者、兼顾英语阅读障碍的 Windows x64 屏幕阅读辅助工具。程序启动后常驻系统托盘，在后台等待鼠标手势；控制中心可以随时隐藏，不会一直遮挡正在阅读的内容。

核心功能分为两层：

- **离线单词点译**：在英文上连续快速按两次鼠标右键，本地 OCR 会识别鼠标附近的单词或短语，并显示词性、简体中文释义、简明英文解释及本地英语发音。
- **AI 长句翻译**：配置并授权首选的 DeepSeek 或 Gemini 后，按住鼠标右键约 `420 ms` 再拖过英文长句；程序先在本地 OCR，只把识别出的英文文本发送给所选 AI，以补充自然整句翻译、英文解释和实际生活用法。

默认的离线点译不联网，也不要求网页、PDF、图片或桌面程序中的文字能够选中或复制。

## 鼠标手势

### 右键双击：离线点译单词

1. 把鼠标指针移到英文单词或短语附近。
2. 在 Windows 设定的双击时间与移动范围内，连续快速按两次鼠标右键。
3. 程序截取鼠标附近的小块画面，在内存中使用 Windows 英语 OCR 定位文字。
4. 识别成功后，屏幕旁弹出紧凑的渐变词典气泡。

气泡可显示英文、音标、词性、简体中文释义、简明英文解释、本地例句或新加坡用法，并可朗读英文原文与英文解释。需要更完整的语境时，可再点击“AI 用法”。

### 单次右键：保留原有右键菜单

单击一次鼠标右键不会触发翻译。程序会等待 Windows 当前的双击判定时间；如果没有第二次右键，便补发这次单击，让网页、文件、文本编辑器等继续打开自己的右键菜单。

因此，普通右键菜单会比完全未启用手势时稍晚出现一小段时间。这个等待时间跟随 Windows 的双击速度设置，不需要按住 `Ctrl`、`Shift`、`Alt` 或其他修饰键。

### 右键长按并拖拽：AI 长句翻译

长句手势只有在以下条件全部满足时才会启用：

- 已选择 DeepSeek 或 Gemini 作为首选服务；
- 首选服务已有可用 API Key；
- 已明确同意把 OCR 后的英文文本发送到该服务的固定主机。

启用后，按住右键约 `420 ms`，再拖过希望翻译的英文长句。清新渐变的选区会跟随拖动；松开右键后，程序在本地截取并 OCR 该区域，然后调用首选 AI 给出：

- 自然的简体中文整句翻译；
- 适合长句的英文解释；
- 词性或句子结构提示；
- 实际生活使用场景；
- 自然英文例句及简体中文说明。

若首选 AI 尚未完成配置或授权，长按拖拽不会启动 AI、不会上传内容，也不会在后台弹出密钥窗口；右键仍按普通右键处理。

这两种翻译手势都只使用鼠标，不要求占用新的键盘组合键，也不会妨碍左键、滚轮和常规鼠标移动。

## 鼠标外观

Luma Translate 不替换 Windows 系统光标。箭头、文本插入光标（I-beam）、网页手形和等待光标会继续按照当前软件与系统状态正常变化，并保留原来的热点与点击精度。

程序只在真实光标旁显示一枚轻量、可穿透点击的动画提示：

- 待命时使用薄荷绿、水蓝和淡紫色的灵动光点；
- 等待第二次右键时显示双点节奏；
- 长句选择时显示 AI 选区状态；
- OCR 或 AI 正在处理时显示动态进度。

动画提示不会接收鼠标点击，也不会改变用户当前的 Windows 光标方案；暂停或退出程序后会直接消失。

## 后台运行与控制中心

- 双击 `SGFloatingTranslator.exe` 后，程序默认进入后台并常驻系统托盘。
- 单击托盘图标可打开控制中心，查看当前模式、手动输入英文、复制结果、朗读原文或解释，以及配置 AI。
- 点击控制中心的“隐藏”、按 `Esc` 或最小化窗口，只会收起界面；已启用的翻译手势继续工作。
- 可从托盘菜单暂停或重新开启翻译手势，也可完全退出程序。
- 暂停手势后，右键立即恢复为原软件的普通行为；退出后不留后台翻译进程。
- Windows 任务栏与通知区域保留其正常交互，托盘菜单始终可用。

## 离线词典与本地 OCR

离线单词点译可显示：

- 英文单词或最长五词的本地短语；
- 本地词典音标与词性；
- 简体中文释义；
- 简明英文解释；
- 本地例句或新加坡英语用法；
- Windows 本地英语发音。

本地模式的实现与数据边界如下：

- OCR 使用 Windows 自带的 `Windows.Media.Ocr` 和已安装的英语 OCR 语言数据。
- 单词点译只截取点击位置所属显示器内、鼠标附近的一小块区域。
- 截图仅存在于内存，OCR 完成后即释放；不写入磁盘、不进入剪贴板、不保存截图历史。
- 内置约 47,000 个 ECDICT 核心英汉词条，并在内存中建立词形索引。
- 新加坡覆盖层包括 `MRT`、`HDB`、`CPF`、`hawker centre`、`kopitiam`、`void deck`、`lah`、`lor`、`shiok`、`chope` 等常见表达。
- 本地未命中不会自动调用 AI，也不会上传截图或英文。
- 不发送遥测或安装标识；最多保留 100 条本次运行中的内存结果缓存。

本地模式最适合单词、固定短语、常见词形与快速阅读辅助。完整长句涉及语法、指代与上下文，应使用已授权的 AI 长句手势；程序不会把本地逐词释义拼接成不自然的整句翻译。

## 配置 DeepSeek 或 Gemini

在控制中心点击“AI 设置”，然后完成以下步骤：

1. 选择首选服务：DeepSeek 或 Gemini。
2. 填写对应的 API Key，或使用受支持的环境变量。
3. 阅读隐私提示，并明确同意向当前服务的固定主机发送识别后的英文文本。
4. 保存设置。只有当前首选服务的密钥与主机授权都有效时，右键长按拖拽才会开启。

### DeepSeek

- API Key 可从 DeepSeek 开放平台获取。
- 固定请求主机：`api.deepseek.com`
- 固定 HTTPS 接口：`https://api.deepseek.com/chat/completions`
- 默认模型：`deepseek-v4-flash`
- 环境变量：`DEEPSEEK_API_KEY`；可用 `DEEPSEEK_MODEL` 覆盖模型。

### Gemini

- API Key 可从 Google AI Studio 获取。
- 固定请求主机：`generativelanguage.googleapis.com`
- 固定 HTTPS 接口：`https://generativelanguage.googleapis.com/v1beta/interactions`
- 默认模型：`gemini-3.5-flash-lite`
- 环境变量：`GEMINI_API_KEY`；可用 `GEMINI_MODEL` 覆盖模型。

两种服务的 Key 与主机授权分别保存。切换首选服务不会把一个服务的 Key 发送给另一个服务。新输入的 Key 可以只在本次运行中保留，也可以使用 Windows 当前账户的 DPAPI 加密保存；应用不会记录或显示完整 Key。

还可使用 `SG_TRANSLATOR_TIMEOUT_SECONDS` 调整 AI 请求超时。

## 隐私边界

- **截图始终留在本机。** 单词点译截图与长句选区截图只用于本地 OCR，绝不会发送给 DeepSeek 或 Gemini。
- **只有 OCR 得到的英文文本会发送给 AI。** 发送内容还包括所选服务所需的 API Key，以及建立正常 HTTPS 连接必需的网络元数据。
- **未经配置与授权不会联网。** 仅填写 Key、仅选择服务或仅长按拖拽都不够；首选服务必须同时具备 Key 和对应主机的明确同意。
- **离线点译不会自动升级为 AI 请求。** 右键双击、本地未命中与本地发音都不会偷偷联网。
- **语音合成在本机完成。** 程序使用 Windows 已安装的英语语音，不把朗读文字交给云端语音服务。

用户仍应避免在密码、密钥、个人身份资料、医疗或财务信息附近使用 AI 长句选区。若内容敏感，请暂停 AI 手势，仅使用离线点译。

## 英文发音

- 默认使用 Windows OneCore 本地语音接口，朗读和音频播放均在本机完成；若现代接口不可用，会自动回退到旧版 Windows 朗读引擎。
- 控制中心可直接选择已安装的英语语音，选择会保存在当前 Windows 用户目录；“安装语音”会打开 Windows 语音设置，安装完成后重启 Luma 即可重新扫描。
- 自动选择时优先 Natural、Neural、HD 或 Windows 已公开的较新语音，再按 `en-SG → en-GB → en-US → 其他英语语音` 排序。本机没有更自然语音包时，会使用 Mark、David、Zira 等可用离线语音。
- 扬声器按钮朗读气泡当前显示的英文；“听解释”朗读当前英文解释。
- AI 结果返回后，朗读内容会随气泡中的解释更新。
- 正常语速经过轻微放缓，慢速模式会进一步降低语速，方便英语阅读与听辨。
- 这是系统合成语音，不是真人录音；实际自然度取决于当前 Windows 安装并向应用开放的语音包，控制中心会显示实际语音名称、地区和性别。

## 系统要求与限制

- Windows 10/11 x64，.NET Framework 4.x。
- Windows 必须安装至少一个英语 OCR 语言。缺失时，应用会提示安装英语语言功能，不会因此自动联网。
- 支持浏览器、Word/PDF 阅读器、普通桌面程序和图片中的清晰英文，不要求文字可复制。
- 极小字号、模糊、低对比、动画、弯曲或严重遮挡的文字会降低 OCR 准确率；可先放大页面再尝试。
- 右键双击需要落在 Windows 的双击时间与移动范围内；其速度可在 Windows 鼠标设置中调整。
- 普通单次右键需等双击判定窗口结束后才会重放，因此右键菜单会有短暂延迟。
- 个别高权限程序、游戏、防作弊程序或特殊输入环境可能阻止全局鼠标监听或模拟的单次右键；可暂停翻译手势后使用原右键。
- UAC 安全桌面、锁屏、密码界面、DRM/受保护视频、部分独占全屏游戏或远程桌面可能无法截图或识别。
- AI 长句质量与响应速度取决于所选服务、模型、网络、额度和原文清晰度；API 可能产生服务方计费。
- 未签名内部测试版可能触发安全软件提醒；正式大规模部署前建议进行代码签名。

## 词库来源与许可证

离线核心库由 [ECDICT](https://github.com/skywind3000/ECDICT) 数据筛选生成。生成脚本为 `source/BuildOfflineDictionary.cs`，嵌入资源位于 `source/data/offline_ecdict_core.tsv.gz`，记录数和 SHA-256 见 `source/data/manifest.json`。第三方说明见 `THIRD_PARTY_NOTICES.md`，许可证见 `licenses/ECDICT_LICENSE.txt`。

当前交付适合作为内部验证版；广泛商业分发前，应根据目标地区和用途独立审核词库数据来源、AI 服务条款、数据传输要求与许可证。

## 重新编译与测试

源码位于 `source`。`source\build.cmd` 使用 Windows 自带的 64 位 .NET Framework 编译器、WinMetadata、本地 OCR 接口和嵌入词库生成 EXE 与测试程序。

```powershell
.\source\build.cmd
.\SGFloatingTranslator.Tests.exe
```

成功时显示 `ALL TESTS PASSED`。
