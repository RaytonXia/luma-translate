# Luma Translate macOS 通用版交付说明

这份工程已经从 Windows 专属实现改写为原生 macOS 实现，目标为：

- macOS 13 或更新版本
- Apple Silicon `arm64`
- Intel `x86_64`
- 一个同时包含两种架构的 Universal 2 应用

## 怎样得到可双击安装的 DMG

当前上传包来自 Windows，而 Apple 的 `.app` 签名、`.dmg` 制作和 Universal 2 最终链接必须在 macOS/Xcode 环境执行。因此工程已内置 GitHub Actions：

1. 把本压缩包内的全部文件提交到你的 GitHub 仓库根目录。
2. 打开仓库的 **Actions** 页面。
3. 选择 **Build macOS Universal**。
4. 点击 **Run workflow**。
5. 构建完成后下载 `Luma-Translate-macOS-Universal` Artifact。

Artifact 中会有 `.dmg`、`.zip` 和 SHA-256 校验文件。工作流会先执行单元测试，再构建两个架构，并用 `lipo -archs` 强制确认 `arm64` 与 `x86_64` 都存在；缺任何一个架构都会直接失败，不会产出伪“通用版”。

## 首次运行必须由用户授权

- **辅助功能**：用于识别并区分普通右键、右键双击和长按拖拽。
- **屏幕录制**：用于把鼠标附近或框选区域交给 Apple Vision 做本地 OCR。

截图不会写入磁盘。AI 未配置 API Key、未选择服务并确认固定目标主机时，不会联网。

## 本次已替换的 Windows 专属部分

- WinForms → SwiftUI + AppKit
- Windows 全局鼠标钩子 → Quartz Event Tap
- Windows OCR → Apple Vision OCR
- Windows DPAPI → macOS 钥匙串
- Windows 语音 → AVSpeechSynthesizer
- 系统托盘 → macOS 菜单栏
- x64 exe → Universal 2 app / dmg

更多技术细节、签名与公证命令见 `README.md` 与 `docs/WINDOWS_TO_MACOS_PORT.md`。
