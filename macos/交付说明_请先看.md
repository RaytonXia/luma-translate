# Luma Translate macOS 1.1.0

直接打开交付的 Universal DMG，将 Luma Translate 拖入 Applications。支持 macOS 13+、Apple Silicon（包括 M1）和 Intel。

同一个 Universal 应用包含 arm64 与 x86_64 两个架构。构建流程会从 DMG 复制应用，在 Apple Silicon 和 Intel 系统启动实际程序，检查词典查询、原生窗口、关闭重开和 Vision OCR。

本次使用 ad-hoc 签名，尚未经过 Apple Developer ID 公证。首次安装来源确认及辅助功能、屏幕录制权限需要由用户在系统设置中完成。首次授予屏幕录制后重新启动应用。

完整的跨应用右键手势需要在获得权限的实际使用环境确认；构建测试不会代替该验收。离线查询不需要 API 密钥，AI 详解需在软件中配置自己的 DeepSeek 或 Gemini 密钥。

保留原有蓝紫色 Logo。详细使用方式见根目录 INSTALL.txt 和 docs/使用手册.md，构建方式见本目录 README.md。
