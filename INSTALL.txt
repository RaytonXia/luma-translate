Luma Translate 1.1.1

Windows：Windows 10 2004 或更高版本 / Windows 11，x64，.NET Framework 4.8。
运行 Setup，安装后从开始菜单打开 Luma Translate。关闭窗口后仍在托盘运行；在托盘菜单选择“退出”即可退出。安装到当前用户目录，无需管理员权限。
屏幕识别需要 Windows 英文 OCR 语言组件。如果提示缺失，在“设置 → 时间和语言 → 语言”中安装英语及其可选组件。

macOS：macOS 13 或更高版本，支持 Intel 和 Apple silicon。
打开 DMG，把 Luma Translate 拖入 Applications（应用程序），从应用程序启动。
首次屏幕取词需要在“系统设置 → 隐私与安全性”允许“辅助功能”和“屏幕录制”。授予屏幕录制权限后重新启动 Luma。
本构建为 ad-hoc 签名，未经过 Apple Developer ID 公证。如果系统阻止首次打开，在核实来源后，在“系统设置 → 隐私与安全性”对本应用选择“仍要打开”。无需关闭系统整体安全保护。

离线查询无需密钥；联网补充释义需要自行配置 DeepSeek 或 Gemini 密钥，并在软件中允许发送所选英文。截图始终留在本机。
词库释义与 AI 补充会明确标注来源；无法保证穷尽所有学科、历史和罕见义项，未知内容不得视为权威答案。
Windows 安装包未使用商业代码签名证书，系统可能提示确认应用来源。
