Luma 原图标资源

本次保留用户原有的双页、文字、声波、点击星芒和鼠标箭头图案，保持原始蓝紫配色。
图案来自用户提供的 Windows 上传包，PNG 和 ICO 内容与原包一致；没有采用重新设计的绿色图标，也没有采用 AI 修复预览。

luma-logo.png：1254 × 1254 原始透明 PNG。
luma-logo-icon.png：512 × 512 紧凑版透明图标。
luma-logo-ui.png：独立的 512 × 512 界面资源，与原 icon.png 相同。Windows 界面直接读取此 PNG，避免放大 32 px 托盘图标。
luma-logo.ico：16、20、24、32、40、48、64、128、256 px 多尺寸 Windows 图标。
macOS 构建时根据原图标生成 ICNS 各尺寸资源；资源放大不等同于增加原始细节。
